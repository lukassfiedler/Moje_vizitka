# Osobní portfolio

Osobní webová stránka vytvořená jako digitální vizitka, která představuje mé dovednosti, zájmy, projekty a cíle v oblasti IT.

🌐 **Živá verze:** [Otevřít portfolio](https://lukassfiedler.github.io/Moje_vizitka/)

## 📌 O projektu

Cílem projektu je vytvořit moderní a přehledné osobní portfolio, které slouží jako prezentace mé osoby, dosavadních zkušeností a projektů. Web je navržen tak, aby byl použitelný na počítači i mobilních zařízeních.

## 🛠️ Použité technologie

- **HTML5** – struktura a obsah webu
- **CSS3** – vzhled, responzivní design, animace a přechody
- **JavaScript** – interaktivní prvky, navigace a filtrování projektů
- **Git a GitHub** – správa verzí a zveřejnění projektu
- **GitHub Pages** – hosting webové stránky

## ✨ Funkce

- Představení autora a jeho zájmů
- Přehled dovedností a projektů
- Filtrování projektů podle kategorií
- Responzivní rozložení pro různá zařízení
- Animované prvky a interaktivní navigace
- Podpora nastavení omezení pohybu pro uživatele, kteří preferují méně animací

## 🚀 Spuštění projektu

1. Naklonujte repozitář:
   ```bash
   git clone https://github.com/lukassfiedler/Moje_vizitka.git
   ```
2. Otevřete složku projektu.
3. Otevřete soubor `index.html` v internetovém prohlížeči.

Projekt využívá čisté HTML, CSS a JavaScript, takže pro základní spuštění není potřeba instalovat žádné další knihovny.

## 🔒 Bezpečnost

Před odevzdáním projektu byly zkontrolovány zdrojové soubory z hlediska přítomnosti hesel, API klíčů a citlivých osobních údajů.

## 📚 Co mi projekt přinesl

Projekt mi umožnil procvičit tvorbu webových stránek, práci s JavaScriptem, responzivní design a správu verzí pomocí Gitu a GitHubu. Zároveň slouží jako základ pro další rozvoj mého portfolia.
